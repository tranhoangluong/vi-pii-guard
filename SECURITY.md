# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories
("Report a vulnerability" on the repository page) rather than in a public issue.

Examples of what counts: PII that leaks through the proxy unredacted in a reproducible pattern,
placeholder mappings readable by another session, PII written to logs.

## Never include real personal data

Do not paste real names, phone numbers, ID numbers, addresses or customer messages into issues,
pull requests or test fixtures. Replace them with invented values that keep the same format.
